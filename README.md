# 手続きの適切性に関する評価型ヴィネット実験（デモ）

`index.html` をブラウザで開くと動作します。外部ライブラリやサーバーは不要です。

## GitHub Pages で公開する
1. GitHubで新しいリポジトリを作成する（公開用ならPublic）。
2. `index.html` をリポジトリのルートにアップロードする。
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save を選択する。
4. 表示される公開URLを共同研究者と共有する。

## 注意
- デモは回答をサーバーに保存しません。ブラウザのページを閉じると回答は消えます。
- 9種類のプロフィールと3種類の実施主体を手動で切り替えられます。
- 「なし」は手続きが実施されないことを意味します。
- 「実施後の対応」は排他的な3水準として暫定的に記述しています。研究上の定義が異なる場合は変更してください。
- 実調査ではランダム割当、同意取得、回答記録、回答者識別などを別途実装してください。
